# Yuchen Dai — Dreamland Resume

A small, walkable 3D resume island built with HTML, CSS, and Three.js.

## Run locally

Serve this folder with any static HTTP server and open the local URL it prints. Three.js is loaded from unpkg, so a network connection is needed for the 3D scene.

## Publish with GitHub Pages

1. Create a public GitHub repository and upload `index.html` and this README to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish. The site URL will appear in the Pages settings, usually as `https://<username>.github.io/<repository-name>/`.

This website includes resume information and a contact email in the UW room. Review those details before making the repository public.
